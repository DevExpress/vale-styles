# `Operate(s)`

- Error: operate and operates
- Correct (not subject to this rule): operating systems and operation modes.
- Example 1:
    - Error: The Chart operates in bound mode only.
    - Correct: The Chart supports the bound mode only.
    - Correct: Only bound mode is available for the Chart.
- Example 2: When bound to the `GridDevExtremeDataSource`, the `TreeList` component switches to the Nodes mode to improve performance.
    - Error: In other data binding scenarios, the `TreeList` operates in `ParentBranch` mode.
    - Correct: In other `TreeList` data binding scenarios, `ParentBranch` mode is active.
